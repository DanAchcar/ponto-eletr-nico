# ⏱️ Sistema de Ponto Eletrônico

Sistema simples em PHP, MySQL, JavaScript e Bootstrap 5 para registro de ponto e cálculo de horas de funcionários.

## 🚀 Como Executar no XAMPP

1. **Baixar os arquivos:**
   Coloque a pasta do projeto em `C:\xampp\htdocs\ponto`.

2. **Iniciar o XAMPP:**
   Abra o XAMPP Control Panel e inicie o **Apache** e o **MySQL**.

3. **Criar o Banco de Dados:**
   * Acesse `http://localhost/phpmyadmin`
   * Clique em **SQL**, cole o conteúdo do arquivo `database.sql` e clique em **Executar**.

4. **Acessar o Sistema:**
   Acesse no navegador: `http://localhost/ponto`

## 🛠️ Tecnologias

* PHP (PDO)
* MySQL
* HTML5 / Bootstrap 5
* JavaScript (Fetch API / AJAX)
